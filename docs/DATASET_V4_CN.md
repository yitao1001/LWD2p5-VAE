# 数据集 lwd_v4：正方形全局窗口上的组合式地质模型

> **版本说明**：lwd_v2–lwd_v4 使用同一套组合式生成器（`lwd_vae/generation.py`，配置 schema 3）。
> - lwd_v2（生成器 2.0.0）：层厚中位数 [0.4, 6] ft。每张图可见层数中位数 8，40% 的图超过 10 层，56% 的可见层薄于 1 ft。用户评估后认为层过密：对 10.67 ft 窗口和 2 MHz/500 kHz 短源距工具而言，大量亚分辨率薄层既不典型，在各向同性反演中也无法分辨。
> - lwd_v3（2026-11-09，生成器 2.0.0）：层厚中位数改为 [1, 8] ft，每张图可见层数中位数约 5，薄于 0.5 ft 的层约 2%。
> - lwd_v4（2026-11-12，生成器 2.1.0）：去掉钙质结核（原为 15% 的模型含 1–3 个高阻透镜体），其余组件和参数与 lwd_v3 相同。用户决定不保留这一类。因此数据中不再有横向有限的孤立地质体。train 中没有结构的平面层序由 28.5% 升到 32.2%，含两种及以上结构的由 30.6% 降到 25.6%；窗口内最大对比度的中位数由 13 倍降到 9.4 倍（结核常高于本模型的最高电阻率级别，会拉大窗口内对比度）。
> - 当前默认数据为 `datasets/lwd_v4`。

lwd_v1 在 2026-11-09 被评估后认为过于理想：
- 84% 的图只有两种电阻率、上下交替；
- 层界全部水平；
- 层厚只有三档；
- 相邻层对比度上限为 1.5 个数量级；
- 四类"起伏层界"在窗口尺度下几何上重复。

lwd_v2 起按用户与本项目讨论确定的方案重写了生成器（`lwd_vae/generation.py`，版本 2.0.0，配置 schema 3）。v1 的设计与结果见 [DATASET_V1_CN.md](DATASET_V1_CN.md) 和 `docs/validation/20261109_lwd_v1_full_training.json`。

完整的生成方法、每个参数的取值与来源、单独示例、组合示例和统计，见面向地质审查的 HTML 报告 `reports/lwd_v4_generation_method_20261112.html`。

## 1. 网格与坐标约定

| 项 | 值 |
|---|---|
| 单元 | 1 inch 正方形 |
| 图像 | `[N,1,128,128]` float32，原始 `log10(ρ/Ωm)`，轴 0 为 z（向下），轴 1 为 y |
| 窗口 | 以窗口中心为原点，y、z ∈ [-5.333, 5.333] ft，即 10.67 × 10.67 ft |
| 展平 | Fortran 顺序（z 最快），参数下标 = `iy*128 + iz`，共 16,384 个 |
| KL-f8 潜变量 | 4 × 16 × 16 = 1,024 个 |
| 坐标系 | 全局 y-z，网格**不随工具倾角旋转** |

这是用户计划中新版反演网格的约定：正方形、全局坐标、始终包含一定数量的收发机。新版反演按以下三点实现即可直接使用这个 VAE：
- 单元大小 1 inch；
- 128×128；
- F 顺序展平。

先验在空间上是平稳的（层界、断层的位置都是随机的），所以不要求窗口与地质原点做绝对位置对齐。v1 的 `check_ver8_grid.py` 不再适用，已删除。等新版反演写好后，再对它做同样的核对。

**倾角的含义**：图像里的倾角是地层本身在井所在竖直剖面上的视倾角，在全局坐标中表示；工具倾角只出现在正演的收发机坐标和方向里，不进入图像。流体界面受重力控制，在全局坐标中始终水平，因此会与倾斜地层斜交。

## 2. 生成流程

每个单元中心按地质历史倒推（`_Scene.evaluate`）。几何在地层坐标中建模：u 沿层面，s 沿层面法向、向下为正。

| 步骤 | 内容 | 主要参数（`configs/lwd_default.json`） |
|---|---|---|
| A 层序 | 每个样本先按对数均匀抽层厚中位数 m；各层厚度服从以 m 为中位数的对数正态分布，再截断 | m ∈ [1, 8] ft（lwd_v2 为 [0.4, 6]）；σ_ln=0.5；截断 [0.2, 12] ft |
| A 电阻率 | 每张图一个"岩性调色板"，含 2/3/4 种岩性，概率 30/45/25%；相邻层必须取不同岩性，同一岩性可以重复出现 | 抽样范围 0.2–500 Ωm；调色板成员间距 ≥ 0.05 |
| A 对比度 | 调色板跨度（最高与最低岩性之差）：25% 取弱对比 U(0.05, 0.3)，75% 取 U(0.3, 2.5) | 跨度就是这张图的最大对比度 |
| B 倾角 β | 整套层序共用；绕窗口内随机点旋转地层坐标 | 60% 取 U(−5°, 5°)，40% 取 U(−15°, 15°) |
| C 起伏 | P=0.3；叠加 1–3 个高斯拱/凹或长波正弦，中心可以在窗口外 | 波长 4–30 ft，幅度 0.1–1 ft，起伏本身的坡度 ≤ 0.35 |
| C 断层 | P=0.3（其中 10% 有两条）；滑移平行于断层面 | 断层面偏离竖直 25–60°（断层倾角 30–65°），断距 0.25–3 ft，正、逆断层都有 |
| D 侵蚀面 | P=0.1；平滑随机曲线（相位随机，相对层理可再倾 ±5°）截断下伏层序，上覆为一套新层序，倾角与下伏相同（不做角度不整合） | 幅度 0.1–1 ft，波长 4–30 ft |
| D 尖灭 | P=0.15；见第 3 节 | 楔形长度 2–20 ft，楔形角 ≤ 30° |
| D 流体界面 | P=0.15；只作用于一种较高阻岩性（厚度 ≥ 0.5 ft 的层可见）；界面以下电阻率降低，可带过渡带 | 降低 0.5–2.0 个数量级，过渡带 0–1.5 ft |
| E 渐变界面 | 每条层界 15% 概率渐变（宽度不超过相邻层厚度的一半） | 宽 0.17–0.5 ft |
| E 层内趋势 | 每层 20% 概率沿 s 方向线性变化 | 变化量不超过 0.2，且不超过跨度的一半 |
| F 厚层 | 3%：窗口内没有层界，只有轻微趋势 | 替代 v1 中完全常数的均匀模型 |

**约束：**
- 两种极端岩性的抖动和趋势只向调色板内侧变化，所以每层都在调色板范围内；
- 流体界面的降低幅度按剩余空间抽取，使整张图最大值与最小值之差不超过 2.5（OOD 对比度集为 3.0）；
- 所有值都在 0.2–500 Ωm 内；
- 窗口内至少要有两个单元（厚层样本除外），否则重抽。

## 3. 尖灭

- **宿主层**：从窗口内可见的层中随机选（不能是层序的首尾层），厚度 ≥ 0.25 ft。
- **收敛方式**：随机为三种之一：
  - 顶面下降：上覆层填入让出的空间；
  - 底面上升：下伏层填入；
  - 上下对称收敛。
- **方向**：朝 +u 或 −u 尖灭，随机。
- **楔形长度**：按对数均匀抽样，下限取 max(2 ft, 移动厚度 / tan 30°)，保证移动的层面相对层理不陡于 30°。ver8 合成楔形约 28°，在这个范围内。
- **尖灭点位置**：让楔形段与窗口重叠即可，所以尖灭点可能在窗口内，也可能在窗口外（窗口里只看到减薄的一段）。metadata 的 `tip_in_window` 记录尖灭点是否可见。
- **可见性**：尖灭至少改变 36 个单元，否则重抽位置。

## 4. 数据划分与标签

| split | 数量 | 说明 |
|---|---:|---|
| train | 40,000 | |
| val | 2,000 | 训练时选模型 |
| test | 2,000 | 独立评估 |
| ood_contrast | 1,000 | 调色板跨度 2.5–3.0，且窗口内实际最大对比度 ≥ 2.5 |
| ood_dip | 1,000 | \|β\| 在 15–25° |

每条 metadata 记录：
- `tags`：planar / undulation / fault / pinchout / erosion / fluid_contact / gradational / trend / thick_bed，一张图可以有多个；
- `contrast_class`：按窗口内最大对比度划分为 none / weak（<0.3）/ moderate（0.3–1.5）/ high（1.5–2.5）/ ood；
- `dip_class`：gentle（≤5°）/ moderate（≤15°）/ ood；
- `span_log10`，以及全部几何参数。

坐标以窗口中心为原点，单位为 ft。`test_vae.py` 按 tag、对比度和倾角分组报告误差；按 tag 分组的样本会重叠，各组数量之和大于总数。

## 5. 生成与检查

```bash
python generate_dataset.py --smoke --preview   # → datasets/lwd_v4_smoke（90 + 4×18）
python generate_dataset.py --preview           # → datasets/lwd_v4，约 8 分钟
.venv/bin/python reports/lwd_v4_generation_method_20261112.py   # → reports/lwd_v4_generation_method_20261112.html
python -m unittest tests.test_generation -v
```

`tests/test_generation.py` 检查的内容：
- 网格约定：1 inch、128×128、F 顺序；
- 每个 split 的重放和取值范围；
- 从图像测出的倾角与参数一致，误差 < 0.5°；
- 断层只移动一侧，正、逆断层都出现；
- 尖灭端厚度为 0，三种收敛方式和尖灭点在窗口内/外两种情况都出现；
- 流体界面在倾斜地层中保持水平；
- 侵蚀面上下分别属于上、下层序；
- 默认配置能产生全部 9 种标签；
- 配置错误能被提前拒绝；
- 端到端生成、去重、重放，以及不覆盖已有数据。

## 6. 仍未包含的内容

- **各向异性**：反演正演是各向同性标量模型。真实泥岩的 Rv/Rh 常见 1–10，这会成为实测数据的模型误差。
- **井眼与侵入**：属于测量环境，不是地质先验。
- **角度不整合**：用户决定不加。
- **孤立地质体**：结核、透镜体、河道砂体等横向有限的地质体都没有（钙质结核在 lwd_v4 去掉）。
- **各组件的比例**：是工程设定，不是从目标区块统计得到的。有邻井测井时，应据此重新标定层厚、电阻率和对比度的分布。
