# VAE 训练、测试与模型接口

默认从头训练；以后有 kl-f8 权重时可以使用 `--pretrained`。新代码直接依赖 PyTorch，不导入原目录中依赖 `ldm`/Lightning 的旧训练脚本，不自动下载任何预训练权重。

本实现保持模型空间 VAE 的思路，默认损失为 **像素 MSE + 界面梯度差 + KL**。它不是 CSEM 论文中 LPIPS/特征损失的逐项复现。优先得到可解释、可测试的地质重构基线；将来比较感知损失时，应保留此配置作为消融基线。

## 2. 正式从头训练

```bash
# 如果还未生成正式数据：
python generate_dataset.py --output datasets/lwd_v1 --preview

python train_vae.py --dataset datasets/lwd_v1 \
  --config configs/train_default.json --device auto --output runs/lwd_scratch_v1

# 训练完成后只加载选好的 best.pt，分别评估三组留出数据。
python test_vae.py --dataset datasets/lwd_v1 \
  --checkpoint runs/lwd_scratch_v1/best.pt --device auto \
  --output evaluations/lwd_scratch_v1 --save-reconstructions
```

三个配置均采用8倍下采样、4通道空间潜变量；48×120图像对应4×6×15=360个潜变量。

| 配置 | 初始通道/每级残差块 | 用途 |
|---|---|---|
| `train_smoke.json` | 8 / 1 | CPU接口检查；2 epochs、8 train、4 val |
| `train_default.json` | 32 / 2 | 默认轻量基线，从头训练；100 epochs、batch16 |
| `train_kl_f8.json` | 128 / 2 | 与现有kl-f8配置对应的完整网络；batch4 |

轻量模型与完整kl-f8具有不同参数形状，**不能把128通道预训练权重部分塞入32通道模型**。两者的空间潜变量形状一致并不意味着权重兼容。实际训练时长/显存需以目标设备实测为准。

所有可调参数写在 JSON 中，未识别的参数会报错。数据集路径、输出路径、设备从命令行传入；`--epochs 200` 可以覆盖目标总轮数。这里未提供多GPU DDP，CUDA使用单个选定设备。

## 3. 损失与模型选择

模型输入由固定的 `log10_bounds` 归一化到 `u=2*(p-lo)/(hi-lo)-1`。不重排矩形网格，不做每张图独立归一化，也不随机翻转/旋转物理坐标。

默认目标为：

\[
L=\mathrm{MSE}(\hat u,u)+0.05L_{\rm grad}+\beta_e\,\mathrm{mean}_{B,C,H_z,W_z}\!\left[\tfrac12(\mu^2+\exp(\log\sigma^2)-1-\log\sigma^2)\right].
\]

`L_grad` 是 y、z 两方向相邻像素差的 MAE 的平均，用于惩罚界面变化丢失。它以每格差值计算，不是每ft导数；若改变网格分辨率，需要重新考虑其权重。`reconstruction` 可设为 `l1`，默认 `mse`。

KL **按潜变量元素取均值**，因此不能直接照搬旧脚本对每个样本潜变量求和后的 KL 系数。默认β在前10轮从1e-5线性增加到1e-4；可用 `kl_warmup_epochs=0` 固定β。训练时从后验采样，验证和测试始终使用后验均值 `decode(encode(u).mode())`，不将随机重构噪声混入模型选择。

训练只读取 `train` 和 `val`：

- `best.pt` 严格保存验证集 **log10ρ RMSE 最低**的轮次；不会使用test/OOD误差选模型。
- `last.pt` 保存最近完整轮次，含模型、AdamW、GradScaler、随机状态、数据指纹和历史。
- early stopping默认patience20；`min_delta`仅决定是否重置等待计数，不阻止保存微小改善的最佳模型。
- 默认float32；CUDA可在JSON设置float16/bfloat16。float16使用GradScaler，溢出的优化步被跳过并记录，CPU/MPS不启用混合精度。
- 验证指标直接在原始log10ρ单位计算，decoder输出**不裁切**；同时记录越界像素比例，避免截断掩盖坏预测。

每个run含 `run_config.json`、`history.csv`、`summary.json`、`best.pt` 和 `last.pt`。history中的epoch从1开始；checkpoint内部epoch从0开始。默认优化器为恒定学习率AdamW，无隐藏调度器、EMA或LPIPS下载。

## 4. 断点续训

续训总轮数而非“增加轮数”由 `--epochs` 指定；写入新目录以保留原实验：

```bash
python train_vae.py --dataset datasets/lwd_v1 \
  --resume runs/lwd_scratch_v1/last.pt --epochs 200 \
  --device auto --output runs/lwd_scratch_v1_continued
```

将 `last.pt` 与同目录的 `best.pt` 一起保留。若last本身就是best，则不依赖旁边的best；否则续训会校验并继承历史最佳权重。也可以从best.pt继续，但这意味着回到该轮次的优化器和随机状态。

续训恢复checkpoint内配置，因此不要同时传 `--config` 或 `--pretrained`。除目标总轮数外不更改优化设置。验证数据集manifest、train/val数组及元数据SHA256，防止把改变过的数据当作同一次实验。随机状态包含Python、NumPy、PyTorch及可用设备的状态，DataLoader按轮次独立seed；精确复现只针对相同软件、设备与数值环境，跨CPU/GPU不保证逐位相同。

## 5. 以后加载预训练权重

```bash
python train_vae.py --dataset datasets/lwd_v1 \
  --config configs/train_kl_f8.json \
  --pretrained /absolute/path/to/kl_f8.ckpt \
  --output runs/lwd_kl_f8_finetune --device auto
```

支持本地CompVis格式独立VAE权重：原始state_dict、包含 `state_dict` 的 `.ckpt/.pt`，或同键名的 `.safetensors`。支持明确的 `model.`/`first_stage_model.` 包装前缀。Diffusers命名、整套Stable Diffusion权重、任意不同架构不自动转换，避免悄悄漏加载；缺少核心权重或形状不匹配都会失败。

RGB→单通道时，encoder首层沿输入通道**求和**，等价于将同一灰度图复制到RGB后卷积；decoder末层沿输出通道取平均。原CSEM脚本的encoder取平均会把该响应缩小3倍，本实现将这个选择明确记录在加载报告。所有层完整校验后才更新模型。`torch.load` 使用 `weights_only=True`，不自动退回任意pickle反序列化。

目前没有用户预训练权重，验证的是结构和构造权重的加载/拒绝逻辑，不能声称已经验证某个外部checkpoint或预训练效果。网络来源与MIT许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 6. 测试输出与解读

测试入口默认处理 `test ood_dip ood_contrast`，可通过 `--splits test` 单独选择。`--max-samples N` 只适合流程检查，结果会明确标注partial_split。OOD含义沿用生成器说明：ood_dip是名义整体倾角，ood_contrast保证保存图像实际对比度超出训练范围。

输出目录中每个split包含：

- `metrics.json`：总体指标，以及按地质家族、弱/强对比分类的统计。
- `sample_metrics.csv`：每张图的误差、越界比例与模型标签。
- `reconstructions.png`：真值、后验均值重构和误差，保留ft坐标、z向下及统一色标。
- `reconstructed_log10rho.npy`：仅在指定 `--save-reconstructions` 时保存；形状 `[N,1,nz,ny]`，原始log10ρ、float64。

主要指标为log10ρ RMSE/MAE、界面相邻差误差、相对线性ρ L2误差及越界比例。总体RMSE从平方误差汇总，不把每批RMSE简单平均。相对ρ误差在log域稳定计算；若超出float64可表示范围，用null及显式overflow计数表示，不裁切ρ后报告虚假的有限误差。

测试允许使用**同坐标、同分辨率、同归一化**但独立生成的数据；不像resume要求完全相同manifest。这便于未来增加独立地质构型集。它不允许隐式resize或把不同窗口大小当作同一模型。

## 7. 用于后续反演的可微接口

```python
import torch
from lwd_vae.inference import LWDVAE

vae = LWDVAE('runs/lwd_scratch_v1/best.pt', device='cpu')
p = torch.full((1, 1, 48, 120), 1.0)  # raw log10rho: 10 ohm m
posterior = vae.encode(p)
z = posterior.mode().detach().requires_grad_(True)
p_hat = vae.decode(z)                  # [1,1,48,120], raw log10rho
vector = vae.decode_inversion_vector(z)  # [1,5760], z fastest/Fortran order
vector.square().mean().backward()      # gradient reaches z
```

权重默认冻结并处于eval模式，仍保留对latent的梯度。没有0.18215等Stable Diffusion潜变量缩放，没有裁切输出，没有改动原GN/正演程序。后续接入时需另行验证生成先验投影、Jacobian链式法则及Hyy/Hzz重构响应误差；本次训练代码不宣称已提高物理反演质量。
