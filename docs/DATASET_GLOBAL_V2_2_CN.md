# 数据集 v2.2：连续背斜、斜断层错移与重新配比

本次根据用户要求，移除 `lens` 透镜状小块异常，继续排除 `block`，加入两种由连续层序变形得到的模型。将“背斜的斜向错开”具体实现为偏斜背斜与斜断层错移背斜。这里是几何先验，未模拟褶皱形成过程、地层年代或应力；比例与尺度是工程配置，不是由真实井区统计拟合得到的。

## 1. 默认配比

| 家族 | 比例 | 20,000 张训练集的数量 | 结构 |
|---|---:|---:|---|
| homogeneous | 5% | 1,000 | 均匀介质 |
| layered | 25% | 5,000 | 水平层状 |
| curved | 10% | 2,000 | 连续缓弯层序 |
| anticline | 15% | 3,000 | 两翼宽度可不同的上拱层序 |
| faulted | 15% | 3,000 | 水平层序被倾斜断层错开 |
| faulted_anticline | 10% | 2,000 | 上拱层序沿斜断层滑移 |
| pinchout | 10% | 2,000 | 单侧延伸并连续尖灭的目标层 |
| unconformity | 5% | 1,000 | 侵蚀面截断较老层序 |
| fluid_contact | 5% | 1,000 | 储层内部流体接触面 |

train/val/test 采用同一比例；整数配额可能导致小样本集有取整差。ood_contrast 排除均匀介质，将其余权重重新归一化。弱/强物性对比仍独立于模型家族抽样。

## 2. 背斜怎样生成

先建立水平参考层界 `z = offset + b_i`。对整组层界施加向上的连续位移：

```text
U(y) = A * exp(-0.5 * ((y-c)/w_side)^2)
z_i(y) = offset + b_i - U(y)
```

`z` 向下为正，因此减去 U 表示上拱。`c` 为轴部位置；轴部左右分别采用独立抽样的 `w_left`、`w_right`，使两翼可具有不同斜率。所有层界共享 U，保持层序有序且不相交，不在背景内单独插入椭圆物体。

当前配置（单位 ft）为：上拱幅度 0.25–0.75；单翼特征宽度 1.5–3.5；轴部位于窗口中心左右 15% 窗宽内，默认即 ±1.5 ft。特征宽度是高斯尺度，不是地质体的有限边界。这些参数适用于当前 10×4 ft 窗口，改变窗口后需重新检查。

## 3. “斜向错开”怎样生成

在背斜上定义一条断层线：

```text
y = y_fault + (z-z_reference) * tan(alpha)
```

alpha 是相对全局竖直方向的断层面夹角；绝对值 20–45°，左右倾向随机。断层一侧沿断层面移动，垂向分量 `throw` 的绝对值为 0.25–1 ft，正负随机；水平分量由 `shift_y = throw*tan(alpha)` 给出。通过反向映射 `(y-shift_y, z-throw)` 计算该侧物性，因此错移既包含高度差，也包含背斜轴部的横向差。

普通 `faulted` 家族仍表示倾斜断层两侧水平层序的垂向错断，断层角范围为 ±20°。这两个家族分别提供平层错断与褶皱错断。

全程使用固定全局 y-z 坐标，不旋转图片。背斜两翼与断层倾角都是地质参数，工具倾角仍作为正演的已知条件。

## 4. 文件与运行

- `configs/lwd_default.json`：唯一默认分布和几何参数来源。
- `lwd_vae/generation.py`：先读 `_anticline_uplift()`，再读 `sample_model()` 的两个背斜分支。
- `datasets/smoke_global_v2_2`：144 张流程检查样本及九类预览。
- `datasets/smoke_global_v2_2/preview_fold_variants.png`：两类背斜各三个样例，选取强对比、参考层界不少于两条的样本以便观察几何；窗口可能裁掉部分层界，选择记录保存在同目录 JSON 中。
- `datasets/lwd_global_v2_2`：正式 25,000 张的默认生成目标，需执行生成命令。
- 正式训练配置为 `configs/vae_finetune_csem.json`，指向本数据集；测试配置位于 `configs/testing/`。
- `references/dataset_global_v2_1/`：旧代码与配置原样备份；旧数据和 checkpoint 保留历史身份。

```bash
# 生成预览集；已有目录会拒绝覆盖，可用 --output 另取目录名。
python generate_dataset.py --smoke --preview

# 生成正式规模数据。
python generate_dataset.py --preview
```

manifest 使用 `generator_version=2.2.0`，数组格式仍为 schema 2、`[N,1,48,120]`、1 inch 单元、原始 log10ρ。样本记录保存两翼宽度、上拱幅度、轴部位置、断层位置、倾向和两个错移分量，支持种子重放。旧配置含 `block` 或 `lens` 会被拒绝；迁移时应使用新版配置补全背斜参数和权重。

## 5. 验证范围

测试检查背斜层界向上拱起、两翼单调、层间距保持、倾斜断层另一侧不变、错移方向覆盖、旧异常家族不可启用、精确配额、平移不改变网格方向、数据完整性和重放。测试记录见 `docs/validation/20261106_anticline_tests.txt`、`DATASET_GLOBAL_V2_2_VALIDATION.json`。

这是代码和数据约定验证。预览需结合目标地层判断尺度与形态；正式 VAE 和 LWD 响应误差仍需单独检验。
